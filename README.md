### 🧸 我在做什么

一个把"好玩的点子"变成"能跑的东西"的人。学的是网络安全，喜欢的是用它和 AI 造出落地的小工具。造出能用的东西，比收藏夹里吃灰的教程有意思得多。

- 🔐 **网络安全**：Web 方向 + CTF，边学边练
- 🤖 **AI 应用**：Coze、MCP、FastMCP、SQLite 这些，拿来搭真能用的东西
- ✨ **小目标**：能在复试和找工作的时候，指着自己的仓库说"这些是我写的"
